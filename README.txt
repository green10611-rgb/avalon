원탁의 기사단 · 자체 서버판 설치 안내 (GitHub + Render, 모두 무료)
=================================================================

이 폴더 구성
- server.js      : 실시간 서버 프로그램 (게임 진행을 서버가 처리해요)
- package.json   : 서버 설정
- public/        : 게임 화면 파일들
- 설치안내.txt    : 이 파일

----------------------------------------------------------------
1단계. GitHub에 올리기
----------------------------------------------------------------
1) https://github.com 가입 후 로그인
2) 오른쪽 위 "+" → "New repository"
   - Repository name: avalon (아무 이름이나 괜찮아요)
   - Public / Private 둘 다 괜찮아요
   - "Create repository" 클릭
3) 만들어진 화면에서 "uploading an existing file" 링크 클릭
4) 압축을 푼 폴더 안의 내용물(server.js, package.json, public 폴더, .gitignore)을
   통째로 끌어다 놓기  ※ 폴더 자체가 아니라 "폴더 안의 것들"을 끌어다 놓아요
5) 아래 "Commit changes" 클릭

----------------------------------------------------------------
2단계. Render에서 서버 켜기
----------------------------------------------------------------
1) https://render.com 접속 → "Get Started" → GitHub 계정으로 가입
2) 대시보드에서 "+ New" → "Web Service"
3) 방금 만든 avalon 저장소 선택 → "Connect"
   (저장소가 안 보이면 "Configure account"에서 Render가 저장소에 접근하도록 허용)
4) 설정값
   - Language(Runtime): Node
   - Build Command: npm install
   - Start Command: npm start
   - Instance Type: Free
5) "Deploy Web Service" 클릭 → 2~5분 기다리면 "Live"가 떠요
6) 위쪽에 나온 주소(예: https://avalon-xxxx.onrender.com)가 게임 주소예요!

----------------------------------------------------------------
사용법
----------------------------------------------------------------
- 방장이 주소를 열고 이름 적기 → "방 만들기"
- 대기실에 QR 코드와 초대 링크가 나와요.
  · 친구들은 폰 카메라로 QR을 찍거나, "링크 복사"/"공유하기"로 받은 링크를 누르면
    이름만 적고 바로 그 방에 들어와요. (전에 이름을 적은 적 있으면 자동으로 들어가요)
  · 4글자 방 코드를 직접 입력해서 들어와도 돼요.
- 사람이 모자라면 방장이 대기실에서 "🤖 AI 참가자 추가"로 AI를 넣을 수 있어요.
  AI는 역할 확인·원정대 고르기·카드 내기·암살을 알아서 하고,
  찬반 투표 때는 화면에 AI의 손(찬성/반대)이 나와요. 그 표까지 세어서 가결/부결을 눌러 주세요.
- 4~10명(AI 포함) 모이면 방장이 시작
- 새로고침하거나 잠깐 끊겨도 같은 방으로 자동으로 다시 들어가요.

----------------------------------------------------------------
알아 둘 점
----------------------------------------------------------------
- 무료 서버는 15분 동안 아무도 안 쓰면 잠들어요.
  다음에 처음 열 때 30초~1분 정도 "서버에 연결하는 중…"이 보이다가 켜져요.
  게임하기 몇 분 전에 미리 한 번 열어 두면 좋아요.
- 서버가 잠들거나 다시 시작되면 진행 중이던 방은 사라져요.
  (게임 중에는 계속 연결돼 있어서 잠들지 않아요)
- 역할 정보는 각 폰에 함께 전달돼서, 개발자 도구를 열면 볼 수는 있어요.
  친구끼리 정직하게 즐겨 주세요.
